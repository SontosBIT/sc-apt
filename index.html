Sc apps

Sc panel for GNOME: a dynamic-island style pill at the top of your screen with a media player, notes and your agenda.

Install on Ubuntu or Zorin OS (GNOME 46)

1

Add the Sc apps repository (once):

curl -fsSL https://sontosbit.github.io/sc-apt/setup.sh | sudo sh
2

Install Sc panel:

sudo apt install sc-panel
3

Turn it on, then log out and back in:

sc-panel-enable

Updates

New versions arrive with your normal system updates, or with sudo apt update && sudo apt upgrade.

Turn it off

Open the Extensions app and switch off Sc panel, or run:

sc-panel-disable

Turn it back on with sc-panel-enable.

Remove

sudo apt remove sc-panel

To remove the repository too: sudo rm /etc/apt/sources.list.d/sc-apt.sources /usr/share/keyrings/sc-apt.gpg
